# ระบบตารางงานและการใช้รถส่วนกลาง

ระบบเว็บสำหรับหน่วยงาน ใช้งานได้จริงบนเครื่องแม่ข่ายของหน่วยงานเอง ผู้ใช้ทุกคนเข้าผ่านเบราว์เซอร์
ด้วยชื่อผู้ใช้/รหัสผ่านที่ผู้ดูแลระบบออกให้ **ไม่ต้องมีบัญชี Claude หรืออินเทอร์เน็ต**

ประกอบด้วย 3 ตารางในระบบเดียว

| ส่วน | ใช้ทำอะไร |
|---|---|
| งานทีม | ตารางรายเดือน แบ่งช่วงเวลาในแต่ละวัน ระบุผู้รับผิดชอบและสถานะ |
| ตารางงานผู้อำนวยการ | ภารกิจรายวัน เวลา สถานที่ ผู้ติดตาม การแต่งกาย สถานะยืนยัน |
| ตารางการใช้รถ / คนขับ | จองรถ + สมุดบันทึกการใช้รถประจำวัน (เวลาออก-กลับ เลขไมล์ น้ำมัน) |

พิมพ์เอกสารราชการได้จากในระบบ

- **แบบ ๓** ใบขออนุญาตใช้ยานพาหนะส่วนกลาง/รถรับรอง (จากใบจองแต่ละรายการ หรือพิมพ์เปล่า)
- **แบบ ๔** สมุดบันทึกการใช้รถส่วนกลาง ประจำเดือน พร้อมสรุประยะทางและช่องลงนาม 3 ช่อง

---

## 1. ติดตั้ง

ต้องมี **Node.js เวอร์ชัน 18 ขึ้นไป** (ดาวน์โหลดจาก nodejs.org — เลือก LTS)

```bash
cd schedule-system
npm install
```

ตั้งรหัสผ่านผู้ดูแลระบบครั้งแรกแล้วเริ่มระบบ

**Windows (Command Prompt)**

```cmd
set ADMIN_PASSWORD=ตั้งรหัสผ่านตรงนี้
npm start
```

**Linux / macOS**

```bash
ADMIN_PASSWORD='ตั้งรหัสผ่านตรงนี้' npm start
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` เข้าระบบด้วยผู้ใช้ **admin** และรหัสผ่านที่ตั้งไว้
(ถ้าไม่ได้กำหนด `ADMIN_PASSWORD` ระบบจะใช้ `admin1234` — ต้องเปลี่ยนทันที)

> ครั้งแรกที่เข้าระบบ ระบบจะเปิดหน้าต่างเปลี่ยนรหัสผ่านให้อัตโนมัติ

### เปิดให้เครื่องอื่นในสำนักงานใช้

รันบนเครื่องแม่ข่าย แล้วให้เครื่องอื่นเข้าที่ `http://<ไอพีของเครื่องแม่ข่าย>:3000`
เช่น `http://192.168.1.50:3000` (อย่าลืมอนุญาตพอร์ต 3000 ใน Windows Firewall)

เปลี่ยนพอร์ตได้ด้วยตัวแปร `PORT` เช่น `set PORT=8080`

## 2. เริ่มใช้งาน

1. เข้าระบบเป็น admin → ปุ่ม **ตั้งค่า**
   - ชื่อและตำแหน่งผู้อำนวยการ
   - หัวกระดาษใบขออนุญาต: ชื่อหน่วยงาน ส่วนราชการ เลขที่หนังสือ และตัวเลือกเว้นที่ว่าง 3 ซม. สำหรับกระดาษครุฑ
   - สมาชิกทีม / ช่วงเวลาในหนึ่งวัน / รถและพนักงานขับรถ
2. ปุ่ม **ผู้ใช้** → เพิ่มบัญชีให้เจ้าหน้าที่ พร้อมกำหนดสิทธิ์
3. เริ่มกรอกงานจริง — ข้อมูลตัวอย่างจะหายไปเองเมื่อบันทึกรายการแรกของเดือนนั้น

### สิทธิ์ผู้ใช้

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| ผู้ดูแลระบบ (admin) | ทุกอย่าง + จัดการผู้ใช้ + สำรองข้อมูล |
| เจ้าหน้าที่ (user) | เพิ่ม/แก้/ลบข้อมูลทุกตาราง แก้ตั้งค่า พิมพ์เอกสาร |
| ดูอย่างเดียว (viewer) | ดูและพิมพ์เท่านั้น แก้ไขไม่ได้ |

หน้าเว็บจะดึงข้อมูลใหม่อัตโนมัติทุก 20 วินาที ผู้ใช้หลายคนจึงทำงานพร้อมกันได้

## 3. ข้อมูลและการสำรอง

ข้อมูลทั้งหมดเก็บเป็นไฟล์ JSON ในโฟลเดอร์ `data/`

```
data/users.json              บัญชีผู้ใช้ (รหัสผ่านเข้ารหัสแบบ scrypt)
data/config.json             ตั้งค่าหน่วยงาน สมาชิก รถ หัวกระดาษ
data/team-2569-09.json       งานทีม แยกตามเดือน (ค.ศ.)
data/director-2026-09.json   ภารกิจผู้อำนวยการ
data/fleet-2026-09.json      การจองรถ
data/fleetlog-2026-09.json   สมุดบันทึกการใช้รถประจำวัน
data/.secret                 กุญแจสำหรับเซ็นคุกกี้ (ห้ามลบ ห้ามเผยแพร่)
```

**สำรองข้อมูล = คัดลอกโฟลเดอร์ `data/` ทั้งโฟลเดอร์** แนะนำให้ตั้ง Task Scheduler คัดลอกทุกคืน
หรือกดดาวน์โหลดไฟล์รวมได้ที่ `http://<เซิร์ฟเวอร์>:3000/api/backup` (เฉพาะ admin)

ลืมรหัสผ่าน admin: หยุดระบบ แล้วสั่ง

```bash
ADMIN_PASSWORD='รหัสใหม่' npm run reset-admin
```

## 4. ให้ระบบทำงานตลอดเวลา

**Windows** — ใช้ [NSSM](https://nssm.cc) ติดตั้งเป็น Service

```cmd
nssm install ScheduleSystem "C:\Program Files\nodejs\node.exe" "C:\schedule-system\server.js"
nssm set ScheduleSystem AppDirectory C:\schedule-system
nssm start ScheduleSystem
```

**Linux (systemd)** — สร้าง `/etc/systemd/system/schedule.service`

```ini
[Unit]
Description=Office Schedule System
After=network.target

[Service]
WorkingDirectory=/opt/schedule-system
ExecStart=/usr/bin/node server.js
Environment=PORT=3000
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now schedule
```

ถ้าเปิดให้เข้าจากภายนอกหน่วยงาน ควรวางหลัง nginx/IIS พร้อมใบรับรอง HTTPS
และแก้คุกกี้ในไฟล์ `server.js` ให้เพิ่ม `Secure` ด้วย

## 5. หมายเหตุเรื่องฟอนต์

หน้าเว็บเรียกฟอนต์จาก Google Fonts ถ้าเครื่องไม่มีอินเทอร์เน็ต ระบบจะใช้ฟอนต์ในเครื่องแทน
โดยอัตโนมัติ (ยังอ่านได้ตามปกติ) ส่วนเอกสารที่พิมพ์ออกมาจะใช้ **TH SarabunPSK ขนาด 16 pt**
ระยะขอบซ้าย 3 ซม. ตามระเบียบงานสารบรรณ ถ้าเครื่องมีฟอนต์นี้ติดตั้งอยู่ (เครื่องราชการส่วนใหญ่มี)
